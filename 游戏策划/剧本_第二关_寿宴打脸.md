# 第二关《寿宴上的不速之客》——游戏剧本(可入游戏稿)

> 改编自小说第二章。本剧本为**分支叙事 + 威慑系统**的可执行脚本,可直接用于原型开发。
> 体量目标:单次游玩 12–18 分钟。
> 形式:2D 立绘对话 + 选项分支 + 威慑结算 + 打脸演出。

---

## 0. 关卡设计目标

| 维度 | 目标 |
|------|------|
| 教学 | 教会玩家**威慑系统**:隐忍累积"反差值" → 亮底牌 → 击穿心理防线 |
| 情绪 | 让玩家亲历"满桌权贵从轻蔑到噤声"的反转爽感 |
| 叙事 | 揭示林昭后台(陆老)的冰山一角,埋下李广平反派线 |
| 系统 | 引入三种底牌:**身份牌 / 后台牌 / 冷场牌**;引入"威望"奖励货币 |

---

## 1. 出场角色与立绘需求

| 角色 | 立绘表情需求 | 关卡内作用 |
|------|--------------|-----------|
| **林昭(主角)** | 平静(默认)、似笑非笑、极冷 | 玩家化身,全程克制 |
| **沈国栋(岳父)** | 得意 → 阴沉 → 青白交替 → 哈腰陪笑 | 主目标,心理防线最高 |
| **沈知夏(小姨子)** | 嚣张、错愕、涨红 | 嘴炮挑衅者,贡献"反差值" |
| **沈未晚(女主)** | 心不在焉、震动、眼圈泛红 | 旁观心动,好感度暗中变化 |
| **李广平(副会长)** | 试探、皮笑肉不笑、僵笑 | 反派伏笔,本关只露头 |
| **陆鸿志(地产大鳄)** | 看戏、眯眼、心惊 | 中立观察者,后续可发展盟友 |
| **安保/保姆/群众** | (剪影/群像) | 围观反应,演出用 |

**场景:** 金陵大酒店三楼大宴会厅。暖金色吊灯、主桌、觥筹交错。基调由"喧闹得意"逐步转向"死寂"。

---

## 2. 关卡状态变量(供程序实现)

```
composure_shen     // 沈国栋心理防线,初始 100,归零=被震慑屈服(过关核心)
contrast_value     // 反差值,玩家隐忍时累积,放大打脸结算
prestige           // 威望(关卡奖励货币),影响后续解锁
favor_weiwan       // 沈未晚好感度(暗记,不显示数值)
card_used_luolao   // 后台牌是否已用(本关限 1 次)
flag_li_marked     // 是否已留意到李广平(影响第三关开局)
```

**底牌(进入本关时玩家已持有):**
- `身份牌·退伍证明`(一等功×3)——中威慑
- `后台牌·陆老电话`——高威慑,本关限用 1 次,滥用触发负反馈
- `冷场牌·沉默以对`——被动牌,隐忍越久威力越大

## 3. 剧本主线(节点式)

> 格式:`【节点ID】` 说话人:台词 `(立绘/演出指示)`
> `▶ 选项` 表示玩家可选;`→` 表示跳转。

### 幕一:不速之客入场

**【N01】** 旁白:江城金陵大酒店,三楼大宴会厅。沈国栋五十大寿。半个江城叫得上号的人物,今天都到了。
`(场景拉远:满堂宾客,暖金灯光,喧闹的祝寿声)`

**【N02】** 沈知夏:`(凑近沈未晚,撇嘴)`姐,那个垃圾真敢来吗?
**【N03】** 沈未晚:`(心不在焉,低头喝水)`……
`(系统提示:沈未晚正在等待一个她说不清的答案)`

**【N04】** 旁白:就在这时,宴会厅大门口,传来一阵骚动。
`(门口安保剪影,推搡)`
安保(画外):哎你站住!请柬呢?今天是沈老爷子的寿宴,没请柬不能进!

**【N05】** 旁白:整个大厅安静下来。所有人的目光,看向门口。
`(全场视线汇聚 → 林昭立绘登场:洗白的旧军绿外套,胶鞋,两手空空)`

**【N06】** 沈知夏:`(拍桌起身)`姐你看!他真敢来!
**【N07】** 沈国栋:`(脸一沉,从牙缝挤字)`林昭?

> **▼ 系统:威慑对决开始。目标——攻破沈国栋的心理防线(composure 100 → 0)。**
> **本关你不必动手。你要选择:何时隐忍、何时亮牌。**

---

### 幕二:嚣张与隐忍(反差值累积)

**【N08】** 林昭:`(走到主桌前停下,声音不大但清楚)`沈伯父。五十大寿,恭喜。

**【N09】** 沈国栋:`(强压火气,皮笑肉不笑)`林昭,我们家不欢迎你。你最好现在转身就走,我可以当你今天没来过。

**【N10】** 李广平:`(斜眼打量)`沈老哥,这位是?
**【N11】** 沈国栋:`(勉强)`一个老熟人,不重要。
**【N12】** 李广平:`(慢悠悠点头)`哦——老熟人啊。
`(系统:这是九年前那个坐在你家客厅、说你是"一堆烂泥"的人。)`

> **▶ 选择 A —— 面对挑衅,你如何回应?**
> - **A1【隐忍】** 不接话,平静地看着他们。`(contrast_value +30,composure_shen 不变)` → N13
> - **A2【硬刚】** "沈伯父,我是来送礼的。"`(composure_shen -10,contrast_value +10)` → N14
> - **A3【亮身份牌·退伍证明】** 直接掏出立功证明。`(过早亮牌:composure_shen -20,但 contrast_value 清零,prestige 奖励减半)` → N15(劣选演出)

**【N13】**(选 A1)旁白:林昭没说话。他只是看着满桌的人。`(立绘:平静)`那种静,让得意的笑容一点点挂不住。
`(系统提示:冷场牌生效。沉默正在累积压力——再忍一会儿,翻盘会更响。)`
沈知夏:`(被这眼神激怒)`你装什么?装什么大人物!→ N16

**【N14】**(选 A2)沈国栋:`(冷笑)`你?送礼?你拿什么送?→ N16

**【N15】**(选 A3 · 劣选)旁白:林昭掏出证明。沈国栋扫了一眼,撇嘴:"一个退伍兵,几张破纸,也敢来我这儿抖威风?"
`(全场哄笑。打脸演出被"提前剧透",观感大打折扣。)`
`(系统:底牌打早了。记住——反差,才是这把游戏的弹药。)` → N16

---

### 幕三:决胜一击(亮后台牌)

**【N16】** 沈国栋:`(拿起茶杯重重放下)`林昭,最后一次,请你出去。

**【N17】** 林昭:`(平静)`沈伯父,我今天是来送礼的。
**【N18】** 沈国栋:`(冷笑)`你拿什么送?

**【N19】** 旁白:林昭从口袋里,掏出一部屏幕开裂的诺基亚。
`(道具特写:裂纹屏亮起)`
林昭:沈伯父,接个电话。

> **▶ 选择 B —— 决胜时刻。`后台牌·陆老电话`** `(card_used_luolao 可用)`
> - **B1【递出电话】** 让他自己看屏幕上的名字。`(触发主结算)` → N20
> - **B2【先不亮,再忍一手】** 收回电话,继续沉默施压。`(若 contrast_value ≥ 50:解锁"极限反差"加成,prestige 额外 +) → 折返 N16 一次后强制 N20;若不足:无加成)` → N16b

**【N16b】** 林昭:`(把电话又收回口袋)`……不急。
`(沈国栋一愣,这份"不急"比任何威胁都让他心里发毛。composure_shen -15,contrast_value +20)` → 回到 N19 递出

---

### 幕四:打脸时刻(招牌演出)

> **🎬【N20 · 打脸过场 · 不可跳过的演出】**
> 严格按 GDD §3.1 演出规范执行:

**【N20-1】** 沈国栋:`(下意识看屏幕)`……
`(镜头:诺基亚裂纹屏,三个字缓缓聚焦——「陆 老」)`

**【N20-2】** 旁白:那三个字,他看第一遍没反应过来。看第二遍的时候——手,开始抖。
`(立绘:沈国栋 得意 → 错愕,手部抖动特效)`

**【N20-3】** 林昭:`(面无表情)`接吧。

**【N20-4】**(接通)沈国栋:`(颤声)`喂……喂?
`(画外苍老威严的声音,只闻其声不见其人,低频混响)`
**【N20-5】** 旁白:整张脸,从青变白,从白变红,又从红变得没了血色。
`(立绘连续切换;背景音乐骤停)`
沈国栋:嗯……嗯……是……明白……首长放心,是,您放心。

**【N20-6】** 旁白:他双手把电话递回去。腰,比刚才弯了三分。
`(演出原子触发:某只手里的茶杯——)`
**【啪。】** `(一只酒杯坠地,清脆碎裂。全场音效抽空,死寂。)`

**【N20-7】** 旁白:整个江城最有钱、最有势的那一桌人,呼吸都停了。
`(群像:陆鸿志 眯眼心惊 / 李广平 僵笑、额角冷汗 / 沈知夏 张嘴合不上 / 沈未晚 心跳如鼓)`

> **💥 威慑结算**
> `composure_shen → 0(屈服)`
> `prestige += base(50) × (1 + contrast_value/100)` ← 隐忍越久,奖励越高
> `card_used_luolao = true`
> 解锁成就:**「礼,我送到了」**

**【N20-8】** 林昭:`(收起电话,淡淡)`沈伯父,礼,我送到了。
**【N20-9】** 沈国栋:`(挤出比哭还难看的笑)`贤……贤婿,坐。

### 幕五:余韵(情感沉淀 + 钩子)

**【N22】** 林昭:`(轻声)`晚晚,过来。
**【N23】** 沈未晚:`(下意识看父亲一眼)`……
沈国栋:`(深吸一口气,咬牙)`去吧。

> **▶ 选择 C —— 当沈未晚走到你身边,你对她说?**(影响 favor_weiwan)
> - **C1** "九年了。今天起,没人再敢扇你妹妹那种巴掌,给你看。"`(原著台词,favor_weiwan ++,触发"眼圈红了"演出)` → N24
> - **C2** `(沉默,只是替她拉开椅子)``(favor_weiwan +,含蓄路线,解锁"无声"小成就)` → N24

**【N24】** 旁白:沈未晚的眼圈,一下子红了。
`(立绘:沈未晚 眼圈泛红;暖光重新打回画面)`

**【N25 · 关卡钩子】** 旁白:走廊尽头,李广平借口离席,掏出了手机……
`(镜头扫到李广平离场背影;若玩家在 N12 留意过他 → flag_li_marked = true)`

## 4. 分支与评级总结

| 玩家路线 | contrast_value | 反差评级 | 演出/奖励 |
|----------|---------------|----------|-----------|
| 全程隐忍 + 二次施压(A1→B2→B1) | 高(≥70) | **S** | 极限反差加成,威望最高,慢镜头加长 |
| 隐忍 + 直接亮牌(A1→B1) | 中(~30) | **A** | 标准打脸演出 |
| 硬刚 + 亮牌(A2→B1) | 低(~10) | **B** | 演出正常,奖励一般 |
| 过早亮身份牌(A3) | 0 | **C** | 打脸被"剧透",奖励减半(教学惩罚,引导玩家理解隐忍价值) |

> **设计意图:** 用评级反馈训练玩家掌握本作的核心节奏——**先受气,后翻盘;忍得越狠,打得越响。**

## 5. 美术 / 音效 / 镜头清单(交付美术与程序)

**立绘(优先级 P0):** 林昭(平静/似笑非笑/极冷)、沈国栋(得意/阴沉/青白/哈腰)、沈知夏(嚣张/错愕)、沈未晚(心不在焉/震动/眼圈红)、李广平(试探/僵笑)。

**关键道具特写:** 屏幕开裂的诺基亚(「陆老」二字聚焦动画)。

**音效原子(可复用模板):**
- `SFX_glass_drop` —— 杯子坠地碎裂(打脸标志音)
- `SFX_silence` —— 背景音骤停 / 环境音抽空
- `SFX_heartbeat` —— 沈未晚心跳(余韵段)

**镜头:**
- 入场:全场视线汇聚门口(光线压暗,聚光林昭)
- 决胜:诺基亚屏幕推近 + 沈国栋手部抖动
- 打脸:杯落地慢镜头 + 群像扫摇 + 死寂留白 1.5s
- 余韵:暖光回归,聚焦沈未晚泛红的眼圈

**BGM 走向:** 喧闹宴会乐 → 决胜段渐弱 → 打脸瞬间静默 → 余韵温情主题轻入。
