# 《判官归来》游戏设计文档(GDD)

> 改编自原创小说《九年战神归来,前妻哭着求复婚》
> 类型:都市复仇 角色扮演游戏(Urban Revenge RPG)
> 文档版本:v0.1(立项策划稿)
> 平台设想:PC / 移动端(横版/竖版均可),单机剧情向

---

## 0. 设计总纲:这部小说该做成什么样的 RPG?

### 0.1 核心矛盾

传统 RPG 的爽点是**"由弱变强"**:主角从新手村一路打怪升级。
但本作的主角林昭,**开场即满级**——他是从尸山血海里爬出来、令人闻风丧胆的"判官"。

所以本作 RPG 的乐趣**不在"变强",而在三件事:**

1. **身份揭露(Reveal)**:别人不知道你是谁。你越平静,反差越大,爽感越强。
2. **震慑碾压(Dominate)**:一个电话、一句话,让满桌权贵腿肚子打转。
3. **收旧账(Reckoning)**:一笔一笔,把九年前欺负过你的人,算回来。

> **一句话设计目标:让玩家体验"我深藏不露,而仇人正在自己作死"的那种从容快感。**

### 0.2 我们不做什么

- ❌ 不做"主角被虐 → 苦练 → 逆袭"的成长曲线(主角已经无敌)。
- ❌ 不做无脑割草。林昭出手要"少而致命",一刀解决比连砍十刀更符合人设。
- ✅ 改为做"**信息差**"的游戏:玩家手里攥着敌人不知道的底牌,选择何时、对谁、如何亮出。

## 1. 故事与世界观

### 1.1 一句话剧情

九年前被岳父陷害送上战场当炮灰的废物赘婿林昭,九年后以"判官"之身归来。等着他的是一份离婚协议——而真正等着他的,是一笔一笔该清算的旧账。

### 1.2 舞台:江城

现代都市。表面是商会、地产、金融编织的繁华,底下是九年前那桩旧案的暗流。

| 区域 | 功能 | 对应剧情 |
|------|------|----------|
| **沈家老宅(城东)** | 主据点 / 关系养成 / 夜袭防守战 | 第1、4、5章 |
| **金陵大酒店宴会厅** | 社交对决主场("打脸"核心场景) | 第2、3章 |
| **远珩集团总部** | 经营/夺权支线,沈未晚的战场 | 第4章(5%股份) |
| **江城商会** | 反派李广平的地盘,情报与对峙 | 第3章 |
| **边境(回忆关卡)** | 战斗教学 / 揭示"判官"由来 | 倒叙穿插 |

### 1.3 主要角色

#### 主角
- **林昭 / 代号"判官"**,29 岁。外松内紧,话少,眼神静得发冷。战斗与威慑双满级,但全程克制。玩家操控对象。

#### 女主(关系养成线)
- **沈未晚**,远珩集团总裁,林昭之妻。从"麻木"到"动心",好感度系统的核心 NPC。九年前曾在窗后想救他而不能。

#### 后台/贵人(身份背书系统)
- **陆老**,神秘大人物,林昭的"干爷爷"。一个电话可让全城颤抖——游戏里是最强的"威慑道具",但有使用代价(不可滥用)。
- **陆鸿志**,地产大鳄。中立老狐狸,可发展为盟友。
- **周厚成 / 李广平(副会长)**,出席寿宴的本地资本。其中**李广平是本作头号反派**。

#### 反派阵营(收账目标)
- **李广平**,商会常务副会长。九年前陷害林昭的实际操办者,是 BOSS。
- **老九**,李广平的打手/跑腿。第5章被林昭反向收编,成为"污点证人"——游戏中是关键情报 NPC。
- **沈国栋**,岳父,五十大寿当天被震慑。半反派,可"挂账不清算",转化为受控盟友。
- **沈知夏**,小姨子,当街扇耳光者。轻量级"打脸"对象,走教育/和解线。

## 2. 核心玩法循环(Core Loop)

```
   收集情报(档案/证据/把柄)
            │
            ▼
   选择对象与时机 ──► 进入【对峙场景】
            │                │
            │         ┌──────┴───────┐
            │     【社交对决】     【战斗对决】
            │     亮身份/打脸       少而致命
            │         └──────┬───────┘
            ▼                ▼
     清算"旧账" ──► 提升威望/解锁新区域/推进感情线
            │
            └──────► 回到据点养成,开启下一笔账
```

每一章 = 收一笔旧账。玩家的成长不是数值,而是**"手里的底牌越来越多、能动的人越来越大"**。

## 3. 招牌系统设计

### 3.1 「威慑值 / 身份揭露」系统(本作灵魂)

代替传统"血条对拼"。每个重要 NPC 有一条 **心理防线条(Composure)**。

玩家通过**亮出底牌**击穿对方防线,而非物理攻击:

| 底牌类型 | 举例 | 效果 |
|----------|------|------|
| **身份牌** | 退伍证明(一等功×3)、"判官"外号 | 中等威慑,对军方/江湖有效 |
| **后台牌** | 陆老的电话 | 超高威慑,但**每章限用,滥用会"贬值"** |
| **证据牌** | 老九的证词、九年前的档案 | 直接击穿特定反派,推进定罪 |
| **冷场牌** | 沉默、平静、以茶代酒 | 反差威慑,对越嚣张的人效果越强 |

> **设计要点:嚣张的敌人(沈知夏、李广平)防线高、但被击穿时"打脸反馈"最爽。**
> 给玩家**慢动作运镜 + 杯子落地音效 + 全场寂静**的过场奖励。

#### "打脸时刻"演出规范(过场)
1. 敌人嚣张挑衅(玩家可选择隐忍累积"反差值")。
2. 玩家打出关键底牌。
3. 镜头扫过围观者:从轻蔑 → 惊愕 → 噤声。
4. 关键道具特写(开裂的诺基亚屏幕亮起"陆老"二字)。
5. 敌人生理反应(冷汗、腿软、弯腰),结算威望奖励。

### 3.2 「旧账簿」系统(任务/进度核心)

一本贯穿全程的账本 UI。每笔账记录:**欠账人、事由、清算方式、状态**。

| 账目 | 欠账人 | 玩家可选清算方式 |
|------|--------|------------------|
| 九年流放 | 李广平(主谋)/ 沈国栋(决策) | 法律定罪 / 商业摧毁 / 武力威慑 |
| 当街耳光 | 沈知夏 | 严惩(停卡) / 宽恕 / 教育转化 |
| 吞没 5% 股份 | 沈国栋 | 索现金 / 夺代理权(原著选择) |
| 夜半引爆 | 李广平(via 老九) | 收编老九反杀 / 报警 / 顺藤摸瓜 |

**设计亮点:同一笔账有多种"算法",对应不同结局走向(见 §6)。** 比如对沈国栋"挂账不清算"会换来盟友;赶尽杀绝则失去远珩集团内应。

### 3.3 战斗系统(克制型即时战斗)

林昭很强,所以战斗要**短、狠、有压迫感**,不做拖沓回合。

- **核心机制:一击制敌窗口(Execution Window)。** 敌人露出破绽的瞬间,精准输入即可秒杀/制服,失败则陷入缠斗(惩罚)。
- **非致命选项:** 多数敌人可选择"制服而非杀死"(如第5章按住老九喉结),影响道德值与情报获取。
- **隐藏匕首:** 标志性道具——"没开刃"的匕首,关键时刻弹出一寸真刃。作为处决技演出。
- **边境回忆战:** 唯一的高强度战斗关卡,解释"判官"由来,也是战斗教学关。

### 3.4 关系养成系统(沈未晚线)

好感度从"麻木/戒备"起步,而非从零。通过**陪伴选择、信任揭露(给她看退伍证明)、守护行为**提升。

- 关键节点:车内坦白(第4章)、夜袭中的保护(第5章)。
- 高好感解锁"双人协作":沈未晚以总裁身份提供商业资源,反哺收账线。
- 结局影响:复婚 / 重新建立信任的不同收尾。

### 3.5 据点经营:远珩集团(轻度策略支线)

夺回 5% 股份与代理权后,开放轻度经营:
- 投入资源 → 解锁情报网络 / 法务团队 / 安保力量 → 反哺主线收账效率。
- 与"挂账盟友"(沈国栋、陆鸿志)的关系决定可用资源上限。

## 4. 关卡 / 章节流程(对应小说前五章)

| 关卡 | 标题 | 玩法侧重 | 教学目标 |
|------|------|----------|----------|
| **序章** | 归来即离婚 | 文字/选择 + 情绪铺垫 | 介绍基调、隐忍机制、伏笔(窗帘、诺基亚) |
| **第1关** | 雨夜回城 | 探索 + 关系初接触 | 据点系统、好感度入门、收到陆老电话 |
| **第2关** | 寿宴上的不速之客 | **社交对决(主菜)** | 威慑系统、后台牌(陆老电话)、首个"打脸时刻" |
| **第3关** | 那个名字叫判官 | 潜行 + 情报 + 对峙 | 偷听李广平密谋、证据收集、身份牌威慑 |
| **第4关** | 收第一笔旧账 | 多选清算 + 经营入门 | 旧账簿系统、夺远珩代理权、道德分支 |
| **第5关** | 半夜来的不速之客 | **战斗 + 反向收编** | 战斗教学、一击制敌、收编老九、引向 BOSS 李广平 |
| (后续) | 收账·李广平 | BOSS 综合战 | 法律/商业/武力三线收束 |

## 5. 数值与节奏设计原则

- **不堆数值堆"筹码"。** 玩家变强 = 底牌变多、人脉变广、证据变全,而非攻击力 +10。
- **反差驱动奖励。** 越是隐忍铺垫充分,打脸结算的"威望"收益越高(连击式 combo 概念)。
- **后台牌稀缺化。** 陆老电话是"核武器",每章至多一次,且滥用会触发负反馈("狐假虎威"恶名,贵人疏远)。
- **节奏:压抑 → 爆发 → 余韵。** 每章遵循"受气铺垫 → 一击翻盘 → 人物情感沉淀"的三段式,匹配爽文呼吸感。

## 6. 分支与结局设想

道德/手段两条隐藏轴决定结局:
- **手段轴:** 雷霆铁腕 ←→ 留有余地
- **情感轴:** 复婚团圆 ←→ 各自珍重

| 结局 | 触发条件 | 基调 |
|------|----------|------|
| **判官归位** | 全员铁腕清算 + 高威望 | 冷峻爽快,独行者 |
| **破镜重圆** | 高好感 + 对沈家留余地 | 温情,前妻哭着求复婚(点题) |
| **江城新主** | 经营线满 + 收编盟友多 | 权谋上位,掌控全局 |
| **不留旧账** | 多数选择宽恕/法律途径 | 救赎向,放下仇恨 |

## 7. 美术 / 演出方向(Mood)

- **整体色调:** 阴雨江城的冷蓝灰,关键打脸时刻切入暖光高对比。
- **标志意象:** 雨、洗白的旧军绿外套、屏幕开裂的诺基亚、没开刃的匕首、二楼东边的窗帘。
- **演出原子:** "杯子落地"音效、全场寂静、敌人冷汗特写——作为可复用的爽点演出模板。
- **UI:** 旧账簿采用宣纸/毛笔质感(呼应"判官"司命意象);威慑条采用裂纹玻璃特效。

## 8. 待决策问题(需立项确认)

1. **视角与画面:** 2D 立绘对话(成本低,贴近原著)还是 2.5D/3D 场景(沉浸强,成本高)?
2. **体量:** 单本五章做成 4–6 小时的精品短剧 RPG,还是按长篇连载持续扩展?
3. **战斗权重:** 战斗作为点缀(更贴小说)还是提升为核心可玩支柱?
4. **付费/发行:** 单机买断、章节付费,还是免费+剧情解锁?

> 以上四点建议在进入详细设计(DDD)前确认。我的默认推荐:**2D 立绘 + 4–6 小时精品短剧 RPG + 战斗点缀 + 单机买断**,最贴合现有素材且开发可控。
